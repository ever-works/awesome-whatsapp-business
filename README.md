## WhatsApp Business API Providers

- [WhatsApp Cloud API](https://developers.facebook.com/docs/whatsapp/cloud-api/) - The WhatsApp Cloud API is Meta's official cloud-hosted API for the WhatsApp Business Platform. It allows businesses to send and receive WhatsApp messages, manage message templates, and integrate WhatsApp into applications without self-hosting infrastructure. The API itself is free to use; Meta charges per conversation based on pricing tiers. ([Read more](/details/whatsapp-cloud-api.md)) `API` `Cloud` `Paid`
- [360dialog](https://360dialog.com/) - 360dialog is a WhatsApp Business Solution Provider offering API access and a shared inbox for customer messaging. It targets businesses that want to connect WhatsApp to their own CRM or helpdesk. Paid plans with message-based fees. ([Read more](/details/360dialog.md)) `API` `Paid` `BSP`
- [Bird](https://bird.com/) - Bird (formerly MessageBird) offers WhatsApp Business API access alongside omnichannel messaging and contact center tools. It serves enterprises needing global reach and unified communications. Pricing is usage-based and volume-dependent. ([Read more](/details/bird.md)) `API` `Paid` `Enterprise` `Omnichannel`
- [Bird WhatsApp API](https://bird.com/whatsapp-api) - Bird is a WhatsApp Business API provider that enables businesses to send notifications, media, and interactive messages from their backend with webhooks for replies and read receipts. The platform supports approved templates, multi-language template management, native Flows for in-chat forms and bookings, AI agents for automated support, commerce catalog sharing, and voice calling escalation within WhatsApp conversations. It also includes analytics for delivery, read, and failure rates by template or country, and number onboarding for new or migrated WhatsApp Business numbers. ([Read more](/details/bird-whatsapp-api.md)) `API` `Enterprise` `Freemium`
- [Gupshup](https://www.gupshup.io/) - Gupshup is a conversational engagement platform providing WhatsApp API, chatbot builder, and campaign tools. It supports enterprises and developers building automated customer journeys. Pricing is usage-based with enterprise agreements. ([Read more](/details/gupshup.md)) `API` `Paid` `Enterprise` `AI Powered` `Conversational Platform`
- [Infobip](https://www.infobip.com/) - Infobip is a cloud communications platform providing WhatsApp Business API, omnichannel messaging, and customer engagement tools. It serves enterprises with global messaging needs. Usage-based enterprise pricing. ([Read more](/details/infobip.md)) `API` `Paid` `Enterprise` `Omnichannel`
- [MessageBird](https://www.messagebird.com/) - MessageBird is an omnichannel communications platform offering WhatsApp Business API access as part of its CPaaS suite. It supports WhatsApp messaging, chatbots, and shared inbox capabilities across multiple channels. Pricing includes a free tier and paid plans based on message volume. ([Read more](/details/messagebird.md)) `CPaaS` `Omnichannel` `Freemium` `Paid`
- [Sinch](https://sinch.com/) - Sinch is a CPaaS and conversational messaging platform that provides WhatsApp Business API access alongside SMS, voice, and email channels. It enables businesses to send notifications, provide customer support, and run marketing campaigns via WhatsApp. Pricing is usage-based with volume discounts, targeted at enterprise customers. ([Read more](/details/sinch.md)) `CPaaS` `Enterprise` `Paid` `API`
- [Twilio](https://www.twilio.com/) - Twilio provides a programmable WhatsApp Messaging API for notifications, customer support, and conversational commerce. Developers and businesses use it to embed WhatsApp into applications. Usage-based pricing with no monthly commitment. ([Read more](/details/twilio.md)) `API` `Paid` `Enterprise` `CPaaS`
- [Vonage](https://www.vonage.com/) - Vonage offers a WhatsApp Business API as part of its communications platform for notifications and customer service. Developers integrate it via REST APIs and SDKs. Usage-based pricing with volume discounts. ([Read more](/details/vonage.md)) `API` `Paid` `Enterprise` `CPaaS`

## Open Source SDKs

- [Baileys](https://github.com/WhiskeySockets/Baileys) - Baileys is a TypeScript and JavaScript WhatsApp Web API library for building WhatsApp bots and automation. It connects to WhatsApp Web and provides functionality for sending messages, managing groups, and handling media. Licensed under MIT, it is free and self-hosted. ([Read more](/details/baileys.md)) `Open Source` `Self Hosted` `Node.js` `WhatsApp Web`
- [Evolution API](https://github.com/EvolutionAPI/evolution-api) - Evolution API is an open-source WhatsApp integration API written in TypeScript. It provides a self-hosted gateway for sending and receiving WhatsApp messages, managing sessions, and integrating WhatsApp into custom applications without relying on the official WhatsApp Business API. Free and open source under the MIT license. ([Read more](/details/evolution-api.md)) `Open Source` `Self Hosted` `TypeScript` `API`
- [GOWA](https://github.com/go-gowa/gowa) - GOWA is a WhatsApp REST API with support for UI, Multi Account, Webhooks, and MCP, and Chatwoot integration. Built with Golang for efficient memory use. Open source and self-hosted. ([Read more](/details/gowa.md)) `Open Source` `Self Hosted` `Go` `REST API`
- [OpenWA](https://github.com/open-wa/wa-automate-nodejs) - OpenWA (wa-automate-nodejs) is a WhatsApp automation framework for Node.js that enables chatbot creation and message automation through WhatsApp Web. It provides a REST API, webhooks, and session management. Open source and self-hosted. ([Read more](/details/openwa.md)) `Open Source` `Self Hosted` `Node.js` `WhatsApp Web`
- [Venom Bot](https://github.com/orkestral/venom) - Venom Bot is a WhatsApp automation framework for building bots and automation tools. It runs on Node.js and connects to WhatsApp Web, providing features for sending messages, managing sessions, and handling media. Open source and self-hosted. ([Read more](/details/venom-bot.md)) `Open Source` `Self Hosted` `Node.js` `WhatsApp Web`
- [WAHA - WhatsApp HTTP API](https://github.com/devlikeapro/waha) - WAHA is a WhatsApp HTTP API (REST API) that can be configured in a click. It supports multiple engines: WEBJS (browser based), NOWEB (websocket nodejs), GOWS (websocket go), and WPP (browser). Written in TypeScript, it is open source and self-hosted. ([Read more](/details/waha.md)) `Open Source` `Self Hosted` `TypeScript` `REST API`
- [Waxum](https://github.com/imtaqin/waxum) - Waxum is an MIT-licensed WhatsApp gateway written in Rust, shipped as a single binary with a REST API and webhooks. It enables WhatsApp messaging and automation without relying on WhatsApp Business API. Open source and self-hosted. ([Read more](/details/waxum.md)) `Open Source` `Self Hosted` `Rust` `API`
- [Whatomate](https://github.com/whatomate/whatomate) - Whatomate is an open-source WhatsApp integration written in Go. It provides a self-hosted solution for WhatsApp messaging and automation through a REST API. ([Read more](/details/whatomate.md)) `Open Source` `Self Hosted` `Go` `API`
- [whatsapp-web.js](https://github.com/pedroslopez/whatsapp-web.js) - whatsapp-web.js is a Node.js library that automates WhatsApp Web via a local browser instance. Developers use it to build custom bots and integrations without an official API. Free and open source under the MIT license. ([Read more](/details/whatsapp-web-js.md)) `Open Source` `Self Hosted` `API` `Node.js` `WhatsApp Web`
- [WPPConnect Manager](https://github.com/wppconnect-team/wppconnect) - Self-hosted WhatsApp REST API built on WPPConnect. Manage sessions, messages, media, contacts, groups and webhooks, with Docker deployment and the WPPConnect Manager UI. Written in TypeScript. ([Read more](/details/wppconnect-manager.md)) `Open Source` `Self Hosted` `TypeScript` `Node.js`
